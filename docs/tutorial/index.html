How these pages work

Every tutorial is a plain HTML page. There is no build step, no JavaScript and no network access: open a page straight from disk, or serve the docs/ folder with any static server.

The pages share the look and navigation of the architecture diagrams. The diagrams remain the place for the visual, whole-system view; these tutorials are the guided route through the source files.

Starting point. Read the core module map in order if you are new to the repository. If you only need one area, the sidebar on each page lists every subsystem directly.
