Fifteen tables in three groups. The sync spine — seven tables hanging off Integration, plus the two scratch tables holding a connect that has not finished — is §1. The identity layer is §2: four tables scoped to User instead, because resolving one company across three connections is by definition not something any one Integration owns. Some columns are strings that are not really strings. Status, type and JSON columns are modelled as String and constrained in application code — a shape inherited from when the tests ran on SQLite, which has neither enum nor Json through Prisma. Everything now runs Postgres, so promoting them to native enum / jsonb is available but not yet done. See §4.
